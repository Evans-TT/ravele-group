# Ravele Royal Farming Enterprise Website

A modern one-page website for Ravele Royal Farming Enterprise (Pty) Ltd.

## Run Locally

```bash
npm run dev
```

Open the local URL shown in the terminal.

## Build For GitHub Pages

```bash
npm run build
```

Upload or deploy the generated `dist` folder to GitHub Pages.

## Project Structure

- `index.html` - page markup and sections
- `styles.css` - responsive visual design and animation states
- `script.js` - splash screen, mobile menu, gallery, lightbox, counters, and scroll interactions
- `assets/` - supplied company and farm imagery
- `scripts/` - dependency-free local server and build helper
